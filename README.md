# 🖱️ Oto Clicker

Python ile geliştirilmiş, pratik ve hızlı bir otomatik tıklama (Auto Clicker) aracıdır. Belirlediğiniz süre boyunca, mouse imlecinizin bulunduğu konuma otomatik olarak tıklama yapar.

## 🚀 Özellikler

* **Zaman Ayarlı Tıklama:** Tıklamalar arasındaki süreyi saniye cinsinden tam olarak ayarlayabilme.
* **Süre Kontrolü:** Toplamda kaç saniye boyunca çalışacağını belirleme.
* **Kolay Konumlandırma:** İmleci hedef koordinata bırakarak kolayca odaklanma.
* **Güvenli Geri Sayım:** İşlem başlamadan önce size hazırlık yapmanız için 3 saniyelik bir pay bırakır.

---

## ⚙️ Nasıl Kullanılır?

1. Programı çalıştırın.
2. Konsol üzerinden her tıklama arasındaki süreyi ve toplam çalışma süresini saniye cinsinden girin.
3. Mouse imlecinizi ekranda tıklanmasını istediğiniz hedef noktaya sürükleyin.
4. 3 saniyelik geri sayım tamamlandığında program otomatik olarak tıklamalara başlayacaktır.
